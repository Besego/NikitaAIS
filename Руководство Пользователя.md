Руководство пользователя АИС "Снабжение комплектующими"
Введение
АИС "Снабжение комплектующими" — это автоматизированная информационная система, предназначенная для управления складом комплектующих, отслеживания продаж и рейтинга поставщиков. Данное руководство описывает функционал системы для двух типов пользователей: обычных пользователей и администраторов.
1. Авторизация и регистрация
1.1 Регистрация

Перейдите на страницу регистрации.
Заполните обязательные поля:
Имя пользователя
Электронная почта
Пароль (не менее 8 символов)


Нажмите кнопку "Зарегистрироваться".

1.2 Авторизация

На главной странице введите:
Электронная почта или имя пользователя
Пароль


Нажмите кнопку "Войти".

2. Функционал для обычных пользователей
После успешной авторизации пользователи получают доступ к трем основным вкладкам: "Мой склад", "Рейтинг" и "История продаж".
2.1 Вкладка "Мой склад"
На этой странице отображаются все комплектующие, принадлежащие пользователю.
Возможности:

Просмотр комплектующих: Список включает название, описание, количество и статус (например, "в наличии").
Добавление новой комплектующей:
Нажмите кнопку "Добавить комплектующую".
Заполните форму:
Название
Категория
Количество
Цена
Описание (опционально)


Нажмите "Сохранить".



2.2 Вкладка "Рейтинг"
На этой странице отображается рейтинг всех поставщиков системы.
Особенности:

Рейтинг формируется на основе количества продаж каждого поставщика.
Список сортируется по убыванию рейтинга.
Для каждого поставщика отображается:
Имя или название
Количество продаж
Средняя оценка



2.3 Вкладка "История продаж"
Здесь отображается информация о всех проданных пользователем товарах.
Особенности:

Для каждой продажи указаны:
Дата продажи
Название комплектующей
Количество
Цена



3. Функционал для администраторов
Администраторы имеют доступ к специальной панели управления с тремя вкладками: "Пользователи", "Комплектующие" и "Продажи".
3.1 Вкладка "Пользователи"
На этой странице отображается список всех зарегистрированных поставщиков.
Возможности:

Просмотр информации:
ID пользователя
Имя пользователя
Действия


Удаление поставщика:
Выберите поставщика из списка.
Нажмите "Удалить".
Подтвердите действие (удаление необратимо).



3.2 Вкладка "Комплектующие"
Здесь отображается полный список комплектующих в системе.
Возможности:

Просмотр деталей:
Название
Количество
Цена
Действия


Удаление товара:
Выберите товар.
Нажмите "Удалить".
Подтвердите действие.



3.3 Вкладка "Продажи"
На этой странице отображается информация о всех продажах в системе.
Возможности:

Просмотр информации:
Дата продажи
Поставщик
Покупатель
Товар
Сумма


Удаление продажи:
Выберите запись о продаже.
Нажмите "Удалить".
Подтвердите действие.



4. Рекомендации по использованию
Безопасность

Используйте надежный пароль и не передавайте учетные данные третьим лицам.

Администраторам

Удаление данных необратимо, убедитесь в необходимости действия перед подтверждением.
Регулярно проверяйте рейтинг поставщиков для выявления аномалий.
